# عالم TV — تطبيق Android وAndroid TV (نموذج أولي)

تطبيق مجاني ومفتوح المصدر للتصفح وتشغيل فيديوهات HTTPS المباشرة، واستيراد قوائم IPTV M3U التي لديك حق استخدامها. لا اشتراك، ولا API مدفوعة، ولا أدوات توليد تحتاج رصيدًا.

## الوظائف
- واجهة عربية تعمل باللمس وبأزرار الريموت مع تركيز قابل للتنقل.
- تشغيل بث HLS (`.m3u8`) وملفات MP4 HTTPS عبر AndroidX Media3.
- مواقع رسمية لقنوات مجانية؛ تفتح عبر المتصفح (وليس مشغلًا مدمجًا للقنوات).
- قسم أفلام مجانية بروابط إلى مصادرها؛ قد يختلف توفر المحتوى بحسب البلد.
- استيراد قوائم M3U بصيغة HTTPS (حتى 2MB / 500 بث لكل عملية)، رابط بث مخصص، بحث ومفضلة محفوظة.
- فيلم تجريبي CC لبيان عمل المشغل.

## البناء للحصول على APK
1. ثبّت Android Studio مجانًا على كمبيوتر Windows / macOS / Linux.
2. افتح مجلد `AlamTV` واختر Sync Gradle؛ سيُحمّل Gradle وMedia3 من المستودعات المجانية.
3. استخدم JDK 17 وAndroid SDK Platform 35 (يمكن تثبيتهما عبر Android Studio).
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ملف الاختبار المتوقع: `app/build/outputs/apk/debug/app-debug.apk`، وانقله للهاتف أو Android TV وثبّته.

## حدود النموذج
- لا يوجد APK مبني أو مُختبر على جهاز فعلي داخل هذا التسليم؛ المصدر يحتاج Android Studio للبناء.
- لا يمكن قانونيًا ضمان كل القنوات أو الأفلام الحديثة مجانًا.
- بعض المواقع قد تتطلب متصفحًا مناسبًا على التلفزيون أو تمنع التشغيل حسب المنطقة.
- قد تمنع بعض القنوات التشغيل المباشر بسبب DRM، أو تغير روابط البث، أو قيود جغرافية.
- لا توجد قوائم IPTV مقرصنة مدمجة.
- إدخال قوائم M3U لا يحفظها بعد إغلاق التطبيق في هذا النموذج؛ المفضلة فقط محفوظة.
- المشغل يقبل HTTPS فقط لحماية المستخدم؛ قوائم HTTP غير مدعومة.

## إنشاء APK مجانًا عبر GitHub Actions (دون تثبيت Android Studio)
1. أنشئ مستودع GitHub جديدًا مجانيًا، ثم ارفع **محتويات مجلد AlamTV** (بما فيها المجلد المخفي `.github`) إلى جذر المستودع. يمكن رفع ZIP بعد فك الضغط محليًا.
2. من تبويب **Actions** افتح **Build free Android APK** ثم **Run workflow**. أو ادفع الملفات إلى الفرع main لتبدأ عملية البناء تلقائيًا.
3. بعد نجاح البناء، افتح التشغيل من Actions وانزل إلى قسم **Artifacts**.
4. نزّل **AlamTV-installable-debug-APK**، فك ضغط ملف النتيجة، وثبّت `app-debug.apk` على هاتف Android أو Android TV.
5. قد تتطلب عملية التثبيت السماح بـ **Install unknown apps** لتطبيق مدير الملفات. فعّل الإذن للمصدر الذي تثق به فقط.

هذا APK بنمط debug موقّع بمفتاح تطوير تلقائيًا؛ صالح للتثبيت والتجربة، وليس ملف إصدار متجر Google Play. يحتاج تنفيذ الخطوات عبر حساب GitHub، وقد تختلف حدود دقائق Actions المجانية حسب نوع الحساب والمستودع.
